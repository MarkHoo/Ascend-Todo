# 目标功能设计文档
## 1. 产品概述
本模块为个人提供 OKR（目标与关键结果）管理工具，核心逻辑为：**周期设定 → 目标(O)拆解 → 关键结果(KR)量化 → 日常任务执行 → 进度追踪 → 复盘归档**。旨在解决个人“有方向无量化、有执行无追踪”的问题。
---
## 2. 核心数据模型
| 实体 | 核心字段 | 关系说明 |
|---|---|---|
| **周期** | 名称、起止时间、状态 | 1个周期包含 N个目标(O) |
| **目标 (O)** | 标题、愿景描述、优先级、进度%、状态 | 1个目标包含 N个关键结果(KR) |
| **关键结果 (KR)** | 标题、类型、目标值、当前值、权重、进度%、状态 | 1个KR下可挂载 N个执行任务 |
| **任务** | 标题、状态(待办/已完成) | 隶属于某个KR，用于日常打卡驱动KR进度 |
---
## 3. 功能详述
### 3.1 周期管理
**页面呈现**：首页顶部为周期切换器（如“2026年度 / 2026 Q1 / 30天挑战”），默认展示当前进行中且最近的周期。
**交互与规则**：
- **新建周期**：输入名称、起止时间。同一时间内允许存在多个进行中周期（如年度目标与季度目标并行）。
- **周期看板**：展示当前周期下的目标完成概览（总目标数、已完成数、平均进度）。
- **归档**：周期结束后可手动归档，归档后数据仅读不可改。
### 3.2 目标制定与管理 (O)
**页面呈现**：以卡片流形式展示当前周期下的所有目标。卡片展示：目标标题、进度环、优先级标签。
**交互与规则**：
- **新建目标**：必填标题，选填愿景描述（解释Why）、优先级（P0/P1/P2）、图标/主题色。
- **目标详情页**：展示愿景描述、总进度环、下属KR列表及关联任务。
- **进度计算**：O的进度 = Σ(KR进度 × KR权重) / ΣKR权重。
- **状态流转**：进行中 → 已达成 / 已放弃。当所有KR均标记完成时，O自动流转为“已达成”。
### 3.3 关键结果量化 (KR)
**页面呈现**：在目标详情页内，以列表形式展示。每行展示：KR标题、进度条、当前值/目标值。
**交互与规则**：
- **新建KR**：必须指定量化类型：
  - **数值型**：如“阅读 20 本书”，需设目标值(20)和单位(本)。
  - **百分比型**：如“完成毕业论文”，目标值固定100%，无需单位。
  - **完成型**：如“通过PMP考试”，目标值固定1，为0/1开关。
- **权重设置**：默认平权(100%)，支持手动调整权重（如KR1占60%，KR2占40%），用于计算O的总进度。
- **进度更新**：
  - 手动更新：点击数值直接修改当前值。
  - 任务驱动：通过完成KR下挂载的任务自动更新进度。
### 3.4 执行任务（连接日常行动）
**页面呈现**：KR列表项可展开/折叠，展示该KR下的待办任务清单。
**交互与规则**：
- **新建任务**：在KR下快速添加轻量级任务（如KR“阅读20本书”下添加任务“读《原则》第1-3章”）。
- **打卡/完成**：勾选任务即标记完成。
- **驱动KR进度逻辑（数值型专属）**：创建任务时可设置“预期贡献值”（如任务“读3本书”贡献值=3）。任务完成时，KR的当前值自动累加该贡献值。
- **独立任务关联**：支持将系统全局“待办清单”中的现有任务，关联至当前KR。
### 3.5 动态记录与复盘
**页面呈现**：目标详情页底部为“动态时间轴”，记录所有进度变更与心得。
**交互与规则**：
- **更新心得**：每次手动更新KR进度时，强制/选填输入一段“心得备注”（如“今天跑了一半差点放弃，但坚持下来了”）。
- **动态流**：按时间倒序展示：[时间] 更新了 KR xxx，进度从 40% -> 60%，备注：xxx。
- **复盘打分**：周期结束后，在归档前可对每个O进行主观打分（1-5星）及总结评价。

## 4. 状态机定义
### 4.1 任务状态
`未完成` ──(勾选)──> `已完成`
`已完成` ──(撤销)──> `未完成`
### 4.2 KR状态
`进行中` ──(当前值 ≥ 目标值)──> `已完成`
`进行中` ──(手动结束)──> `已放弃`
*(注：KR一旦完成/放弃，其下未完成任务自动标记失效，不再驱动进度)*
### 4.3 目标(O)状态
`进行中` ──(所有KR均为"已完成")──> `已达成`
`进行中` ──(手动结束)──> `已放弃`
---
## 5. 核心计算规则（开发必看）
### 5.1 KR进度计算
- **数值型**：`Progress = (Current_Value / Target_Value) * 100` (上限封顶100%)
- **百分比型**：`Progress = Current_Percentage` (上限封顶100%)
- **完成型**：未完成 = 0%，已完成 = 100%
### 5.2 目标(O)进度计算
设某O下有 n 个 KR，第 i 个 KR 的进度为 $P_i$，权重为 $W_i$：
`O_Progress = Σ(P_i * W_i) / Σ(W_i)`
### 5.3 任务驱动KR更新逻辑（仅数值型）
当KR下某任务标记为“已完成”，且该任务包含预期贡献值 $V_{task}$：
`KR.New_Current_Value = KR.Old_Current_Value + V_{task}`
随后触发 KR进度计算，再触发 O进度计算。

## 6. 关键交互状态说明
| 场景 | 触发条件 | UI表现/系统行为 |
|---|---|---|
| **进度溢出拦截** | KR当前值 > 目标值 | 进度条满格100%，数值显示红色提示超预期，但不影响权重计算（按100%算） |
| **目标提前达成** | O下所有KR均已完成 | O卡片打上“已达成”勋章，进度环变绿，卡片置底或移入“已达成”分组 |
| **权重动态变更** | 新增/删除/修改KR权重 | 实时重算O的总进度，进度条平滑过渡动画 |
| **周期到期** | 当前日期 > 周期结束日期 | 首页周期名称旁出现红点提示“待复盘”，O卡片进度条锁定不可更新，需先复盘归档 |
