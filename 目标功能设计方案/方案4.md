# 目标功能设计文档
## 一、产品概述

- 结构化：将零散计划转化为"目标+可量化关键结果"的标准体系
- 落地化：目标直接关联个人待办任务，打通想法到执行的链路
- 可视化：直观展示目标进度，快速识别拖延与滞后项
- 可沉淀：归档历史目标与复盘记录，长期追踪个人成长轨迹

## 二、核心功能设计
### 2.1 个人目标管理
#### 功能定义
支持用户创建、编辑、删除、查询个人全维度目标，统一管理工作、学习、生活等不同场景的计划。
#### 核心规则
- 唯一层级：仅保留个人目标，无上下级对齐、无跨目标依赖
- 目标类型：默认提供工作、学习、生活、成长、自研项目5类，支持用户自定义新增/编辑类型
- 目标字段
  - 必填：目标名称、目标类型、开始时间、截止时间
  - 可选：目标描述、个人权重（1-10分）、自定义标签
- 目标状态：未开始（0%）、进行中（1%-99%）、已完成（100%）、已延期、已暂停

### 2.2 关键结果（KR）管理
#### 功能定义
将个人目标拆解为可量化的关键结果，用于衡量目标完成程度。
#### 核心规则
- 单个目标可关联1-5个KR，支持自由增减
- KR进度加权平均计算对应目标的整体进度
#### KR字段
- 必填：KR名称、衡量标准（数量/百分比/次数等）、基准值、目标值、开始时间、截止时间
- 可选：进度备注、执行心得
#### 进度计算
- 手动更新：用户直接输入实际值，系统自动计算进度
- 自动计算：关联个人任务后，按任务完成率自动核算KR进度

### 2.3 目标-个人任务联动
#### 功能定义
打通目标与个人待办任务，实现执行进度自动同步。
#### 联动规则
- 支持将任意个人任务关联至目标或单个KR
- 个人任务标记为"已完成"时，自动同步更新对应KR及目标进度
- 支持从目标详情页直接新建关联任务，无需页面跳转
- 目标详情页集中展示所有关联任务的状态与进度

### 2.4 进度可视化与数据统计
#### 个人目标仪表盘
- 核心指标：全部目标总数、各状态目标数量、整体目标完成率
- 展示内容：近期重点目标进度预览、延期目标高亮提醒
- 筛选能力：支持按时间周期（日/周/月/年）、目标类型、状态筛选
#### 个人数据报表
- 支持报表：目标完成趋势图、各类型目标完成占比、KR达成统计
- 导出能力：支持将报表导出为Excel/PDF格式自用

### 2.5 归档与复盘
#### 功能定义
沉淀历史目标与执行经验，为后续目标制定提供参考。
#### 核心规则
- 自动归档：目标完成或超出截止时间7天后自动归入历史目标库
- 手动归档：支持用户手动归档任意状态的目标
- 个人复盘：归档时可填写完成总结、问题反思、经验沉淀、优化方向
- 模板复用：支持将优质目标（含KR配置）保存为个人专属模板

### 2.6 提醒与预警
#### 功能定义
通过系统通知提醒用户跟进目标进度，避免遗漏。
#### 提醒场景
- 目标/KR即将截止（提前3天、1天）
- KR进度滞后（截止前3天完成率不足50%）
- 每日待办目标推送
- 支持用户自定义开启/关闭各类提醒

## 三、交互设计规范
### 3.1 核心页面布局
1. **目标列表页**
   - 顶部：筛选栏（时间、类型、状态）+ 快速新建按钮
   - 中部：目标卡片列表（展示名称、进度、截止时间、状态标签）
   - 右侧：个人数据概览卡片
2. **目标创建/编辑页**
   - 单页表单布局，分"基本信息"和"关键结果"两个区块
   - 支持动态添加/删除KR条目
3. **目标详情页**
   - 顶部：目标基本信息（名称、进度、时间、类型）
   - 中部：KR进度列表 + 关联任务列表
   - 底部：复盘记录 + 操作日志

### 3.2 关键交互逻辑
- 进度更新：点击KR进度条可直接输入实际值，实时生效
- 批量操作：支持批量修改目标状态、批量归档目标
- 搜索：全局搜索支持匹配目标名称、KR名称、标签关键词
- 状态切换：目标/KR状态变更自动触发进度重算与提醒

## 四、数据结构设计
### 4.1 个人目标表（personal_goal）
| 字段名 | 字段类型 | 是否必填 | 说明 |
|--------|----------|----------|------|
| id | bigint | 是 | 目标唯一主键 |
| user_id | bigint | 是 | 所属用户ID |
| name | varchar(255) | 是 | 目标名称 |
| type | varchar(50) | 是 | 目标类型 |
| start_time | datetime | 是 | 开始时间 |
| end_time | datetime | 是 | 截止时间 |
| progress | decimal(5,2) | 是 | 整体进度（0-100） |
| status | tinyint | 是 | 0未开始/1进行中/2已完成/3延期/4暂停 |
| description | text | 否 | 目标描述 |
| weight | tinyint | 否 | 个人权重（1-10） |
| tag | varchar(255) | 否 | 自定义标签 |
| is_archive | tinyint | 是 | 0未归档/1已归档 |
| review_content | text | 否 | 复盘内容 |
| create_time | datetime | 是 | 创建时间 |
| update_time | datetime | 是 | 更新时间 |

| 字段名 | 字段类型 | 是否必填 | 说明 |

| id | bigint | 是 | KR唯一主键 |
| goal_id | bigint | 是 | 关联目标ID |
| name | varchar(255) | 是 | KR名称 |

| baseline | decimal(18,2) | 是 | 基准值 |
| target_value | decimal(18,2) | 是 | 目标值 |
