# 目标功能设计文档

## 1. 产品定位
帮助用户设定目标、分解关键结果、记录进度，并直观看到完成情况。

## 2. 用户核心场景
- 设定一个目标（如“三个月减重5公斤”）
- 拆解成可量化的关键结果（如“每周跑步3次”）
- 定期更新进度（如“本周跑了2次”）
- 查看整体完成度，获得成就感

## 3. 功能范围

### 3.1 目标管理
- **创建目标**：标题、起止日期、描述（选填）
- **编辑/删除目标**
- **目标状态**：进行中、已完成、已放弃
- **周期灵活**：支持年/季/月/周或自定义日期范围

### 3.2 关键结果（Key Result）
- 每个目标下可添加 **1～5 个** KR
- KR 类型：
  - **数值型**：有目标值、当前值、单位（次/小时/公斤等）
  - **布尔型**：完成 / 未完成（如“学会弹一首歌”）
- 手动更新当前值，自动计算进度百分比
- 更新时可添加备注（如“今天状态很好”）

### 3.3 子任务（可选）
- 每个 KR 下可添加 **非量化** 的子任务清单（Checklist）
- 子任务仅标记完成/未完成，不参与进度计算

### 3.4 进度可视化
- 主页面：目标卡片展示**整体进度条** + **剩余天数**
- 详情页：每个 KR 独立进度条 + 数值变化趋势图（折线图）

### 3.5 历史与复盘
- 已完成/已放弃的目标移入“历史”列表
- 目标结束时，可记录复盘笔记（成功/失败原因）

### 4.3 创建目标流程
1. 点击主页“＋创建”按钮
2. 弹出表单：
   - 目标标题（必填，50字内）
   - 起止日期（默认当月1日～当月最后一日，可修改）
   - 描述（选填）
3. 点击“添加关键结果” → 填写标题、选择类型（数值/布尔）、填写目标值
4. 可重复添加最多5个 KR
5. 保存 → 返回主页，新目标出现在列表顶部

## 5. 数据模型

### 5.1 实体关系
```
Goal (1) ──has many──► KeyResult (1) ──has many──► Subtask
```

### 5.2 Goal 目标
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| title | string | 标题 |
| description | string | 描述（可选） |
| startDate | date | 起始日期 |
| endDate | date | 结束日期 |
| status | enum | `active` / `completed` / `abandoned` |
| createdAt | datetime | 创建时间 |
| updatedAt | datetime | 最后更新时间 |

### 5.3 KeyResult 关键结果
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| goalId | string | 所属目标ID |
| title | string | KR标题 |
| type | enum | `numeric` / `boolean` |
| targetValue | number | 目标值（数值型时必填） |
| currentValue | number | 当前值（数值型，默认0） |
| unit | string | 单位（数值型时填，如“次”） |
| isCompleted | boolean | 是否完成（布尔型时使用） |
| progressHistory | array | 进度更新记录 [{ value, note, date }] |

### 5.4 Subtask 子任务
| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 唯一标识 |
| keyResultId | string | 所属KR ID |
| content | string | 任务内容 |
| isDone | boolean | 是否完成 |

## 6. 非功能要求（仅设计约束）
- **离线可用**：所有数据存储在本地（LocalStorage / IndexedDB）
- **响应式**：同时适配手机竖屏和桌面浏览器
- **操作即时反馈**：任何增删改操作后，界面在 200ms 内更新

## 7. 边界与约束
- 每个目标最多 5 个 KR（避免过度复杂）
- 数值型 KR 的目标值必须为正数
- 起止日期不能超过 5 年跨度
- 删除目标时弹窗确认，并级联删除其下的所有 KR 和子任务
