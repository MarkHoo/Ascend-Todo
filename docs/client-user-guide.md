# 光阶Todo客户端使用手册

本文面向桌面客户端用户，说明光阶Todo的主要功能、推荐工作流和常见注意事项。

## 1. 产品定位

光阶Todo 是一款本地优先的桌面效率工具，核心目标是帮助用户把任务、目标、日程和专注时间放在同一个工作台里管理。

适合场景：

- 个人任务管理。
- 项目推进和看板协作。
- 年度、季度、月度目标跟踪。
- 日程规划和时间块安排。
- 番茄钟专注与复盘。
- 多设备之间同步个人数据。

## 2. 首次启动

首次安装后，客户端会根据系统语言和当前日期生成示例数据。示例数据用于展示产品能力，包括：

- 示例任务看板。
- 示例目标和关键结果。
- 示例日程。
- 示例 Markdown 描述。

这些示例只会在首次创建本地数据库时生成。已有用户升级不会重复插入示例。

## 3. 数据保存位置

Windows 默认数据目录：

```text
%APPDATA%\com.ascend.todo\
```

本地 SQLite 数据库：

```text
%APPDATA%\com.ascend.todo\ascend.db
```

卸载正式安装包时会清理本地数据目录。开发调试时如果需要模拟首次安装，可以手动删除该目录。

## 4. 总览

总览页用于快速查看近期状态。

主要内容：

- 今日任务。
- 近期日程。
- 目标进度。
- 专注统计。
- 激励语。

推荐用法：

1. 每天打开软件先查看总览。
2. 从今日任务中选择最重要的 1-3 件事。
3. 查看日历是否存在冲突。
4. 使用番茄钟开始第一个专注块。

## 5. 任务看板

任务看板适合管理具体行动。

核心概念：

- 看板：一个项目、领域或长期计划。
- 列表：任务所处阶段，例如待处理、进行中、等待反馈、已完成。
- 卡片：具体任务。
- 子任务：任务内部的拆解步骤。

常用操作：

- 新建看板。
- 新建列表。
- 新建任务卡片。
- 拖拽卡片调整顺序或移动到其他列表。
- 设置任务优先级、开始时间、截止时间、提醒。
- 在任务描述中使用 Markdown。
- 将任务关联到目标或关键结果。

建议：

- 一个看板只放一个明确领域。
- 列表不要过多，通常 3-5 个足够。
- 卡片标题写行动，不写空泛主题。
- 复杂任务拆成子任务。

## 6. 目标

目标用于跟踪比任务更长期的成果。

支持内容：

- 目标标题和说明。
- 开始日期和截止日期。
- 目标状态。
- 里程碑。
- 关键结果。
- 关键结果权重。
- 目标关联任务。
- 复盘评分和备注。

推荐流程：

1. 创建一个季度或月度目标。
2. 添加 2-4 个关键结果。
3. 为关键结果设置可衡量数值。
4. 把相关任务关联到关键结果。
5. 每周更新一次进度。

## 7. 日历

日历用于安排时间。

视图：

- 日视图。
- 周视图。
- 月视图。

支持内容：

- 普通日程。
- 全天日程。
- 从任务生成的时间块。
- 节假日。
- 调休补班标记。
- 未安排任务拖拽到日历。

建议：

- 短任务可以直接拖到日历安排时间。
- 专注工作使用 45-90 分钟时间块。
- 不要把全天都排满，保留缓冲时间。
- 周视图适合做每周规划，月视图适合看整体节奏。

## 8. 番茄钟

番茄钟用于记录专注时间。

支持模式：

- 倒计时。
- 正计时。
- 运行中切换模式。
- 关联任务。
- 完成后记录统计。

建议：

- 开始前先选择一个任务。
- 短任务用倒计时。
- 探索型任务用正计时。
- 每天结束后查看专注统计，复盘最有效的时间段。

## 9. 个人资料

个人资料用于设置本地显示身份和账号同步状态。

支持：

- 头像。
- 昵称。
- 个性签名。
- 登录账号。
- 邮箱验证。
- 云端同步开关。
- 登录设备管理。

说明：

- 头像只保存在本机，不参与云同步。
- 昵称和个性签名会同步。
- 邮箱未验证时不能使用云同步。

## 10. 云同步

云同步用于在多设备之间同步数据。

同步前置条件：

1. 已登录账号。
2. 邮箱已验证。
3. 已开启云端同步。
4. 当前设备未被移除。

同步内容：

- 任务看板和任务。
- 目标、里程碑、关键结果。
- 日历事件。
- 番茄钟记录。
- 设置项。
- 昵称和个性签名。

不同步内容：

- 头像。
- 邮箱授权 token。
- 本地缓存。
- 日志。
- 安装包缓存。

登录后的数据处理：

- 本机无数据、云端有数据：自动从云端恢复。
- 本机有数据、云端无数据：提示是否上传本机数据。
- 本机和云端都有数据：提示选择合并、上传本机、恢复云端或暂时跳过。

## 11. 设备管理

在个人资料页可以查看登录设备。

可执行操作：

- 重命名设备。
- 移除其他设备。
- 请求其他设备下次联网时清理本地数据。

当前设备不会显示移除按钮，避免误操作。

## 12. 设置

设置页包含：

- 外观和界面大小。
- 主题。
- 语言。
- 窗口行为。
- 日历设置。
- 番茄钟设置。
- 数据与隐私。

建议：

- 屏幕较小或分辨率较高时，可以调大界面大小。
- 日历用户建议优先设置每周开始日、默认提醒和默认日程时长。
- 如果经常多设备使用，建议登录并验证邮箱后开启云同步。

## 13. 常见问题

### 卸载重装后为什么还有数据？

新版正式安装包卸载时会清理本地数据。如果是开发环境或旧安装包，可能需要手动删除：

```text
%APPDATA%\com.ascend.todo\
```

### 为什么看不到首次示例？

示例只在首次创建本地数据库时生成。如果本地数据目录已经存在，就不会重复生成。

### 邮箱未验证能同步吗？

不能。必须完成邮箱验证码验证后才能开启云同步。

### 头像为什么不同步？

头像属于本机隐私和大体积资源，目前只保存在本地。

### 远程移除设备会立刻删除旧电脑数据吗？

如果旧设备在线，可以收到清理请求。如果旧设备离线，只能在它下次联网后处理。
