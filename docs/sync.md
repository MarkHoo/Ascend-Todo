# 云同步设计

当前使用本地优先 + 云端快照同步，并通过云端版本号保护多设备并发写入。

## 同步前置条件

1. 用户已登录。
2. 邮箱已验证。
3. 当前设备未被撤销。
4. 用户状态为 active。

## 同步范围

同步任务、目标、番茄、复盘、日历事件、设置和个人资料文字信息。

不同步头像、邮箱授权 token、本机缓存、安装包缓存和本机路径。

## 冲突保护

客户端会记录最近一次知道的云端版本 `remoteVersion`。

推送时带上 `baseRemoteVersion`：

- 如果云端版本没有变化，允许上传。
- 如果云端版本已经被其他设备更新，返回冲突，客户端提示先执行智能合并。

## 智能合并

智能合并流程：

1. 拉取云端快照。
2. 按记录 `id` 合并本地和云端数据。
3. 对存在 `updatedAt` 的记录选择更新时间更新的一份。
4. 设置项以本机为准补充到合并结果。
5. 合并后写回本地并上传云端。

## 退出登录

退出前必须检查未同步数据。

默认退出只清 token，不删除本机数据。

用户明确选择“退出并清除此设备数据”时，才删除当前用户本地数据库和缓存。

## 远程移除设备

远程移除设备会撤销 refresh token 和设备授权。

如果用户勾选“请求下次联网清理”，服务端写入 `wipe_requested_at`。旧设备下次联网后执行清理并回写 `wiped_at`。
