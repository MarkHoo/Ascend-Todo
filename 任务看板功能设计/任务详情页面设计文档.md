# 任务详情页面布局

```text
+----------------------------------------------------------+
| 任务详情                                              [X] |
+----------------------------------------------------------+
| 任务标题: [ 可编辑文本输入框                           ]   |
+----------------------------------------------------------+
| 当前状态: [ 进行中 ▼ ]   优先级: [ 最高 ▼ ]   开始时间: [ 2026-03-15 ]   截至时间: [ 2026-04-20 ] |
+----------------------------------------------------------+
| > 任务信息 <     子任务                                   |
+----------------------------------------------------------+
|  描述                            [编辑图标] [全屏查看图标] |
|----------------------------------------------------------|
|   这里是任务描述的详细内容。在点击[编辑图标]后进入支持富文本和Markdown的编辑状态|
|   支持多行文本显示，并可在切换后显示子任务列表。点击子任务后的任务详情页面布局和这个一致的基础上，在任务标题上面加一行 【父任务：[当前任务的父任务标题]】，并且可以点击打开对应的父任务详情页面|
|                                                          |
|                                                          |
+----------------------------------------------------------+
```

重点提示：
- 任务标题默认为可编辑状态
- 当前状态 下拉列表按顺序包含：未开始、进行中、长期任务、已完成、关闭。默认状态为 【未开始】。
- 优先级 下拉列表按顺序包含：普通、最低、较高、最高、较低。默认优先级为 【无】。
- 当软件设置为中文的时候，开始时间和截至时间日期选择的星期一等等这些显示为中文的 【一二三四五六日】，同时年月显示为 【2026年6月】这种和设置语言一致的语言。总之就是日期选择框显示的文字也要和设置中的语言保持一致！ 

- 任务描述 和 子任务 两个按钮并列显示在同一行可点击切换，然后显示对应的内容。
